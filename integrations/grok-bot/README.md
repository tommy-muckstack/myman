# MyMan for GrokBot

Skill-only Agent Plugin package. Install this directory as the plugin root in a compatible host. Its skill uses GrokBot's approved execution on the user's Mac, where MyMan and Node.js 22+ must be installed. It does not start a stdio MCP server on GrokBot's cloud computer.

This package is prepared for submission; marketplace listing and a live Hugo invocation have not been verified. See [submission and verification status](../../docs/grok-bot-marketplace.md). The repository-root plugin separately provides read-only MCP for clients running locally on the Mac.
