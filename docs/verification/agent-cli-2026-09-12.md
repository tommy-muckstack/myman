# Agent CLI and marketplace preparation — verification

Baseline: main `f65df27` (MyMan 1.1.59 / 71). Working branch: `feat/agent-cli-marketplace`. Local preview: 1.1.60-preview / 72. No installed app or personal library was replaced. The root checkout's unrelated edits were left untouched. This document records local evidence, not a marketplace listing or a live GrokBot invocation.

## Results

- Full Swift suite: **149 tests, six opt-in skips, zero failures**. The skipped tests require optional private-copy/UI/model review; they are not counted as verified.
- CLI/MCP/packaging suite: **66 tests, zero failures**. Includes command mapping and native schema compatibility, file-based markup, JSON/exit errors, timeout/job behavior, retrieval filters, official MCP client fixture retrieval, and official Agent Plugins schema validation for both manifests.
- Real native action harness: **52 of 52 advertised actions exercised**, plus all **10 read-only Brain tools** against fixture exports. This includes screenshot import/capture/window capture/capture-markup/edit/OCR, clipboard, screen video start/mic/stop/cancel, meeting start/title/stop/discard/config/notes, dictation start/stop/cancel, notes, tasks, themes, settings, fonts, and deletion/job-cache invalidation.
- Resource/action CLI against the native app: **29 successful/expected-error command checks**. Actual window capture, capture-markup, image editing, copy, recording stop/cancel, note append/search, stale-revision protection, tasks, theme membership, and confirmed deletion.
- Default-off native CLI: **10 checks**, including capture, markup, meeting/dictation/video start, note/delete refusal and inability to self-enable agent grants. All expected error exits verified.
- **Universal release compilation passed** for arm64 and x86_64.
- Bundled helper resolves its app resources and discovers app.doctor. Both skills pass the skill-creator frontmatter validator. Bundle freshness is checked separately.

The comprehensive native harness includes expected error outcomes: stale note revision → EDIT_CONFLICT; a flat screenshot can yield NO_FOREGROUND for background removal; silent dictation can yield TRANSCRIPTION_FAILED; unconfirmed clear-history → CONFIRMATION_REQUIRED. Meeting notes were retrieved for a fixture with an existing summary; this test does not evaluate new summarization quality. Webcam-on was not exercised because it would need Camera permission; the off path and option validation were tested.

Pixel tests verify that Retina image metadata matches encoded PNG pixels, separate annotation colors at the image's actual backing scale and that pixelation samples the requested top-left region. The latter exposed and fixed an existing vertical-coordinate bug. Schema/consent tests verify default-off behavior, the two grants required by capture-markup, destructive confirmation, diagnostics/stop availability after grants are disabled, and rejection of grant keys in settings.update.

## Reproduce

```sh
npm ci --ignore-scripts --prefix integrations/brain
npm test --prefix integrations/brain
npm run check-bundle --prefix integrations/brain
swift test
swift build -c release --arch arm64 --arch x86_64
python3 scripts/package-local.py
```

Start the preview with `MYMAN_VERIFICATION_ROOT=/private/tmp/man-verification-cli-denied` and no agent-access override, then run `node integrations/brain/test-cli-live.mjs /private/tmp/man-verification-cli-denied --denied`.

Stop only that preview. Start it with a fresh fixture root and `MYMAN_VERIFICATION_AGENT_ACCESS=enabled`, then run the happy-path CLI test and `test-all-native-actions.mjs` on that same fixture root. The environment override is debug-only and affects the preview's preferences. macOS permissions remain real. Never run a destructive harness against the production socket or personal Brain.
